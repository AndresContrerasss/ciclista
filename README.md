# Sistema de Gestión de Carrera Ciclística 🚴‍♂️

Proyecto desarrollado en **Java** bajo un entorno **Maven**, enfocado en la gestión orientada a objetos de una competencia de ciclismo y sus diferentes tipos de corredores (como Velocistas, Contrarrelojistas, Escaladores, entre otros).

## 🛠️ Estructura del Proyecto
El código fuente se encuentra organizado dentro del paquete principal `com.carrera`[cite: 2, 5], implementando conceptos clave de la programación orientada a objetos como:
* **Herencia**: Clases derivadas a partir de una clase abstracta base (`Ciclista`)[cite: 2].
* **Encapsulamiento**: Atributos privados con sus respectivos métodos de acceso (`getters` y `setters`)[cite: 2].
* **Polimorfismo**: Sobrescritura de métodos (`@Override`) para la impresión de tipos de ciclistas y sus estadísticas[cite: 2].
